# 🎓 CampusConnect – College Student Dashboard

CampusConnect is a modern, responsive College Student Dashboard website developed using **HTML5 and CSS3** as part of my frontend web development learning journey.

The website provides a centralized interface where students can view their academic information, attendance, examination results, class timetable, subjects, assignments, notifications, and college announcements.

## 🚀 Features

- **Student Profile:** Displays student information, course, branch, semester, and academic year.
- **Dashboard Overview:** Shows attendance percentage, average marks, total subjects, and pending assignments.
- **Attendance Tracking:** Displays overall attendance with a circular progress indicator.
- **Academic Performance:** Shows subject-wise marks and performance progress bars.
- **My Subjects:** Displays enrolled subjects with faculty names and attendance percentages.
- **Weekly Timetable:** Provides a structured Monday-to-Saturday class schedule.
- **Examination Results:** Displays internal marks, assignment marks, examination scores, totals, and grades.
- **Assignment Tracker:** Shows pending and completed assignments.
- **Notifications:** Displays important academic updates and reminders.
- **College Announcements:** Highlights examination schedules, workshops, events, and other college updates.
- **Responsive Design:** Supports desktop, laptop, tablet, and mobile screens.

## 💻 How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your browser.
5. Alternatively, use the Live Server extension in VS Code.
